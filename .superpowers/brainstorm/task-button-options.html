  • 원본 워드의 제출, 회의 열기, Codex 위임 흐름에 더 가깝습니다.
  • 협응도 높은 task에서 변경 요청과 회의 요청을 자연스럽게 다룰 수 있습니다.
  • Codex 버튼은 회의 맥락, 결정사항, 근거, 필요한 자료, 완료 기준을 묶은 상세 작업 패킷을 만듭니다.
  • 버튼이 많아서 Slack 상태 관리와 권한 처리가 커집니다.
