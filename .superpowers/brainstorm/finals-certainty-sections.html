2번. 확인 대기 섹션을 따로 둠
#finals · 하드웨어
하드웨어 누적 결과
확정 결정
ESP32를 우선 검토 대상으로 삼는다.
확인 대기
라즈베리파이는 대안으로만 남기고 구현 기준은 ESP32로 옮기는 흐름으로 보입니다.
근거: 이후 논의가 ESP32 기준 데이터 송신 방식으로 이어졌습니다.
확인 대상: 조수현님, 김조은님, 배민성님
미결정
모델 실행 위치를 ESP32/라즈베리파이/노트북 중 어디로 둘지 결정되지 않았습니다.
차이: 1번은 단순하지만 “확인만 받으면 확정될 내용”이 일반 미결정과 섞입니다. 2번은 확인 대기 항목이 따로 보여서 팀이 무엇을 확인해야 하는지 명확합니다.
