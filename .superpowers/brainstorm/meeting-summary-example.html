회의 핵심 요약

오늘 회의는 하드웨어 선택, Wi-Fi 데이터 수집 방식, 다음 시연 전까지의 개인별 task 재배치를 중심으로 진행되었습니다. 가장 큰 결정 후보는 라즈베리파이 기반 설계를 ESP32 중심으로 바꿀지 여부입니다.

주제 1. 하드웨어 방향

  • 주장김조은은 ESP32가 센서 연결과 전력 측면에서 현재 주제에 더 적합하다고 주장했습니다.
  • 근거라즈베리파이는 기능이 많지만, 이번 기능 검증에는 과하고 세팅 시간이 길 수 있습니다.
  • 영향배민성의 데이터 수집 방식과 조수현의 모델 실행 구조에 영향을 줍니다.

주제 2. Wi-Fi 정보 수집

  • 강의실 502, 503호의 Wi-Fi ID와 연결 가능 여부 확인이 필요합니다.
  • 수집 결과는 하드웨어 선택과 데이터 송신 방식 판단에 사용됩니다.

미결정 사항

  • ESP32로 변경할지 최종 승인 필요
  • 시연 전까지 라즈베리파이 대안을 유지할지 여부
