Subjector Scope Map

워드 파일 기준으로 기능을 겹치지 않게 나눈 첫 지도입니다. 지금은 구현이 아니라 범위 결정 단계입니다.

Core Loop
1. 회의 기록
오프라인 녹음 업로드
화자 구분 전사
Slack Huddle AI Notes 유사 스크립트
2. 회의 이해
주장, 근거, 맥락 정리
주제별 묶음
결정/변경사항 추출
3. 태스크 반영
개인별 task 생성/변경
협응 필요도/중요도
의견 충돌 시 회의 유도
4. Slack 실행 화면
채널 글 + 스레드 UI
제출, 회의 열기, Codex에서 진행
5. 하루 요약
사람별 오늘 한 일
중요도 상/중/하 정렬
모두에게 공유
A

회의 기록부터

녹음 업로드, 전사, 회의 요약, task 추출까지 먼저 검증합니다.

B

태스크 운영부터

Slack에서 오늘 할 일, 결정, 제출, 요약의 실사용 루프를 먼저 만듭니다.

C

얇은 전체 루프

전사 성능은 임시로 두고, 회의 기록에서 태스크와 하루 요약까지 end-to-end를 작게 연결합니다.
