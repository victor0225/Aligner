ESP32와 라즈베리파이 비교 후 추천안 작성
상태: 완료
회의 맥락: 하드웨어 선택이 데이터 수집 방식과 모델 실행 구조에 영향을 줍니다.
수행 도우미: 전력, 센서 연결, 구현 난이도, 시연 안정성을 기준으로 비교하세요.
결정 필요: ESP32로 변경할지, 라즈베리파이를 유지할지 추천 근거 작성
중요도: 상 · 협응도: 상
완료 요약: ESP32 추천. 전력/센서 연결/시연 안정성 측면에서 현재 프로젝트에 더 적합함.
김조은 · Codex 결과 붙여넣기
[수행 결과] - ESP32와 라즈베리파이 5 8GB를 전력, 센서 연결, 구현 난이도, 시연 안정성 기준으로 비교했습니다. [결론] - 현재 MVP 시연 기준으로는 ESP32를 추천합니다. [근거] 1. 센서 연결과 데이터 송신 중심의 기능 검증에는 ESP32가 더 직접적입니다. 2. 전력 사용과 휴대성 측면에서 라즈베리파이보다 부담이 적습니다. 3. 라즈베리파이는 모델 실행에는 유리하지만, 이번 task의 핵심은 센서/통신 검증이므로 과할 수 있습니다. [영향받는 task] - 조수현: 모델 실행 구조를 라즈베리파이 기준에서 분리해 검토해야 합니다. - 김조은: ESP32 기준 센서 연결 후보를 계속 정리합니다. - 배민성: Wi-Fi 연결 테스트를 ESP32 기준으로 확인해야 합니다. [추가로 필요한 결정] - 모델 실행을 로컬 라즈베리파이에서 할지, 외부 서버/노트북에서 할지 결정 필요 [첨부/링크] - ESP32 공식 문서 링크 추가 예정
